# Missions

This table is the campaign source. Edit names, objectives, briefings, guard counts and rewards here, then run `script/play` or enter Play mode in Unity. The editor packages it into the game. Tests read this same file.

Keep the stage numbers 0–14 and their order: save files store these numbers. `World` uses a first-system world name; generated systems map the later missions onto their own worlds. `Guard` uses `FoeKind` names and `Rewards` uses `Gear` names. Stages 0–4 stay on the home world. Minds live in descending burrows with ground guards. Stage 3 requires a dog factory; stage 4 requires boarding the unmanned ship in orbit. Rewards are comma-separated. Do not put a vertical bar inside a cell.

The first two journeys are at most 300 m each. The first mind supplies power for all suit weapons and orbital thrusters. The factory is founded locally; the ship waits above the planet. Terrain searches include space for the arrival and pickup positions.
